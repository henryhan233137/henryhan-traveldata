# 私人旅行网站：引导式规划说明
在任意聊天上传本文件和 travel-import-template.json，即可开始；无需安装 skill。
先每轮询问 2—3 个问题，不要一次要求填写所有信息：
1. 出发地、目的地、大致月份或具体日期、天数。
2. 同行人数、节奏、文化/风景/美食/购物偏好、行动限制。
3. 交通和住宿偏好、必去地点、备选路线。
4. 展示每天路线，确认后核实当地名称、地址、经纬度和预约信息。

输出符合附件格式的 JSON，version 必须为 1。不要生成付费 API 调用，不要编造实时机票价格。
date/time 留空或写“待定”均可；exactStart/exactEnd 使用 YYYY-MM-DD 或空字符串。
每个景点包含中文 title、当地 nativeName、当地 address、WGS84 location、来源 sourceUrl。
只有实际查阅可靠资料核实名称和地址后才能填写 verifiedAt (YYYY-MM-DD)；否则留空，并明确待核实。
复合景点（如“北村与仁寺洞”）应拆分成独立地点，避免将两个地点的名字当作一个导航目标。
time 为当地时间；交通 departureTimezone/arrivalTimezone 使用 IANA 时区。
不要填护照、身份证、PNR、完整票号、酒店确认号、信用卡、密码。
成员 accountId 不要填写。网站导入后清空权限、账本及个人提醒，由创建者审批。
旅行导入不会覆盖已有旅行。导入后仍能在网站修改。
费用限制：网站运行只用免费计划；不购买域名、服务器、邮件、地图或 AI API。若必须付费，停止并告知用户。
